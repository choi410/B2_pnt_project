# 한 줄에 "단계 :: 질문". 각 질문은 그 단계의 일이 "지금 진행되고 있는가"만 묻는다. 고치면 재시작 없이 다음 판단부터 적용된다.
수주/사양협의 :: 고객과 계약 내용이나 장비 사양을 협의·검토·확정하고 있는가?
설계(기구/전장) :: 도면 작성, 도면 승인, 설계 검토(DR), 상세설계가 진행되고 있는가?
구매/제작 :: 부품의 가공·제작·외주가 진행되고 있어 그 진행 상황을 점검하고 있는가?
조립/사내시운전(FAT) :: 사내에서 설비 조립이나 사내 시험(FAT)이 진행되고 있는가?
현장셋업(SAT) :: 설비가 고객 현장에 반입되어 설치나 현장 시험(SAT)이 진행되고 있는가?
양산/CS :: 설비가 고객 공장에서 양산에 쓰이고 있는가?

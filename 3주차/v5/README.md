# PNT 회의록 서비스 v5

2026-11-19 최신 통합본입니다. 팀원 UI·검수·승인 기능, 최신 AI 대화 개선,
흐름의 진행단계 클릭 수정과 재클릭 취소를 포함합니다.

## 다른 Windows 컴퓨터에서 실행

1. **이 v5 폴더 전체**를 내려받습니다. ZIP이면 먼저 압축을 풉니다.
2. **Python 3.12 64비트**를 설치합니다. Python Launcher와 PATH 등록을 선택합니다.
3. `01_처음한번_설치.cmd`를 실행합니다. 최초 설치에는 인터넷이 필요합니다.
4. `02_서비스실행.cmd`를 실행합니다. 준비되면 브라우저가 열립니다.
5. 주소는 **http://127.0.0.1:8776/** 입니다. 김양일 계정으로 시작하면 됩니다.

실행 창은 열어 둡니다. 종료는 해당 창에서 `Ctrl+C`입니다.
화면 빌드 결과가 포함되어 있어 **사용만 할 때는 Node.js 설치가 필요 없습니다.**
기존 8775 서비스와 데이터·쿠키·포트를 분리했습니다.

로그인 세션·비밀번호 정보·이전 AI 대화·임시 업로드·실제 메일 설정은 포함하지 않았습니다.

## AI 분석과 AI 대화 사용 준비

**화면 실행과 AI 실행은 준비 조건이 다릅니다.**
기본 설치만으로 기존 예제·변경이력·캘린더·원문을 볼 수 있습니다.
새 회의록 분석과 의미 검색·생성형 답변을 사용하려면 아래를 추가로 진행합니다.

1. NVIDIA CUDA 지원 GPU와 호환 드라이버를 준비합니다. 현재 생성 엔진에는 BF16 지원이 필요합니다.
2. `03_AI환경설치.cmd`를 실행합니다. PyTorch 등 수 GB의 라이브러리를 설치합니다.
3. `04_모델다운로드.cmd`를 실행합니다. 고정 리비전의 공개 모델을 다운로드합니다.
4. `05_환경점검.cmd`에서 `BASIC SERVICE: READY`, `AI: PREREQUISITES READY`를 확인합니다.
5. 서비스를 종료했다가 `02_서비스실행.cmd`로 다시 실행합니다.

| 용도 | 모델 | 폴더 |
| --- | --- | --- |
| 회의록 분석·답변·단계 판단 | unsloth/Qwen3-4B-Instruct-2507-bnb-4bit | 프로그램/b2-model/models/base |
| 의미 검색 | intfloat/multilingual-e5-small | 프로그램/b2-model/models/multilingual-e5-small |

모델 가중치와 가상환경은 Git에 올리지 않습니다. 모델을 이미 받았다면 위 두 모델 폴더를
복사해도 됩니다. **.venv는 PC마다 새로 설치**해야 합니다.
생성 모델은 개발 PC의 NVIDIA GPU 8GB 환경에서 사용했습니다. 속도와 사용 가능 여부는
GPU 메모리·드라이버·다른 실행 프로그램에 따라 달라집니다. GPU 없는 PC에서 같은 AI가
동일하게 실행된다고 보장하는 패키지는 아닙니다. 환경 점검은 실제 추론 성공 보장과 다릅니다.
이 실행본은 다른 프로그램의 8080 AI 서버에 자동 연결하지 않고 포함된 로컬 모델 구성을 사용합니다.

## 짧은 확인 순서

1. 홈에서 프로젝트 6개와 캘린더를 확인합니다.
2. 한빛셀 → 변경이력: 속도 120→135 m/min 합의, 커버 요청 철회, 납기 변경 보류를 확인합니다.
3. 흐름 → 진행단계 이름을 누릅니다. 같은 단계를 다시 누르면 취소되며, 저장을 누르면 반영됩니다.
4. 회의록의 원문 PDF와 근거 문장 강조 표시를 확인합니다.
5. AI 준비 후 `예제회의록`의 A4 PDF를 추가 등록합니다. 검토 완료 후 납기 12/18→12/23 반영을 확인합니다.
6. AI에서 “회의록을 월별로 찾아줘” → “여기서 11월 회의록만 모아줘” → “프로젝트별로 묶어줘”를 확인합니다.

`예제회의록`에는 추가 등록용 PDF 2개와 같은 내용의 예비 TXT가 있습니다.
**PDF와 TXT를 중복 등록하지 않습니다.** B3는 서린배터리의 온도 140℃ 요청 철회 사례입니다.
한빛셀 PM은 김양일, 서린배터리 PM은 배근우입니다.
사전 등록된 자료는 AI 결과를 원문과 대조하여 보완한 예제입니다. 검토 없이 모두 자동 확정된 결과가 아닙니다.

## 저장 위치와 Git 업로드

- **업로드할 것은 이 v5 폴더 전체**입니다. 숨김 파일 `.gitignore`, `.gitattributes`도 포함합니다.
- `프로그램` 안에 서비스 소스·화면 빌드·모델 실행 코드·예제 데이터를 모았습니다.
- 각 컴퓨터의 실제 데이터는 `프로그램/b2-service/data/v5/`에 저장됩니다.
- Git에서 `.venv`, `node_modules`, 모델, 실제 데이터·업로드·로그·비밀 설정을 제외합니다.
- `프로그램/sample-data/`의 JSON과 PDF는 배포할 가상 예제이므로 Git에 포함합니다.
- 각 PC의 데이터는 독립적입니다. **Git으로 코드를 받아도 이후 회의록이 서로 자동 동기화되지는 않습니다.**
- 사용 중인 자료를 옮기거나 백업할 때는 서버 종료 후 `data/v5` 폴더 전체를 복사합니다.
  DB 파일만 옮기면 원문 PDF가 빠집니다. 새 경로의 원문 연결은 시작할 때 갱신합니다.
- 이름 선택 로그인으로 사용하는 로컬 시연용입니다. 기본 주소는 자기 PC에서만 접속됩니다.

## 문서와 승인 메일

글자가 포함된 PDF·DOCX·XLSX·TXT·MD를 등록할 수 있습니다. 스캔 이미지 OCR은 포함하지 않습니다.
DOCX 원본 페이지 미리보기에는 Windows용 Microsoft Word가 필요합니다. Word가 없으면 추출 텍스트를 확인합니다.
예제는 PDF라 Word 없이도 원문을 볼 수 있습니다.

검수·승인 기능은 유지했습니다. 메일은 기본적으로 **미발송(console)**이며 실행 창에 내용을 출력합니다.
SMTP 비밀 설정은 전달하지 않았습니다. 자기 PC의 localhost 승인 링크는 외부 고객이 접속할 수 없습니다.
외부 승인 메일을 실제 운영하려면 별도의 서버 주소·접속·메일 설정이 필요합니다.

네이버 메일로 발송하려면 다음을 설정합니다.

1. 네이버 메일에서 **환경설정 → POP3/IMAP 설정 → POP3/SMTP 설정 → 사용함**을 저장합니다.
2. 네이버ID의 **보안설정 → 2단계 인증**을 설정하고 **애플리케이션 비밀번호**를 발급받습니다. 일반 로그인 비밀번호로는 연결할 수 없습니다.
3. `프로그램/b2-service/.env.example`을 같은 폴더의 `.env`로 복사합니다.
4. `.env`에서 `MAIL_MODE=smtp`, `SMTP_USER=발신 네이버 메일 주소`, `SMTP_PASSWORD=발급받은 애플리케이션 비밀번호`를 입력합니다. 서버 주소와 포트는 `smtp.naver.com`, `465`로 준비되어 있습니다.
5. 서버를 종료한 뒤 **02_서비스실행.cmd**로 다시 실행합니다. 이미 테스트 모드에서 처리한 요청은 자동으로 재발송되지 않습니다.

계정 비밀번호는 `.env`에만 입력합니다. 이 파일은 Git에서 제외되며, 다른 PC에서는 별도로 설정합니다.
[네이버 공식 SMTP 안내](https://help.naver.com/service/30029/contents/21341) · [애플리케이션 비밀번호 정책](https://help.naver.com/notice/noticeView.help?lang=ko&noticeNo=22533&serviceNo=30029)

## 문제 해결

- Python을 못 찾으면 3.12 **64비트** 설치를 확인합니다. 3.14만 설치되어 있으면 이 설치 스크립트에서 사용하지 않습니다.
- 설치 실패 시 같은 01 파일을 다시 실행합니다. 오류가 남으면 실행 창의 오류 내용을 확인합니다.
- 8776 포트 사용 중이면 이미 켜진 v5 창을 확인합니다. 다른 서비스가 쓰고 있다면 그 서비스를 종료한 뒤 실행합니다.
- 원문이 안 열리면 v5 폴더 전체와 `data/v5/files`를 함께 옮겼는지 확인합니다.
- AI가 동작하지 않으면 05의 **AI 항목**과 03·04 완료 여부를 확인합니다.
- 한글·공백 경로를 지원합니다. 설치된 `.venv`를 다른 경로로 옮긴 경우 환경을 새로 설치하는 것을 권장합니다.

Python 경로를 직접 지정해야 할 때는 v5 폴더에서 다음처럼 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\프로그램\portable.ps1 -Mode Setup -Python "D:\Python312\python.exe"
```

## 개발자용

실행 진입점은 `work.v3.server:app`입니다. 폴더명 `work/v3`은 내부 경로이며 배포 버전은 **5.0.0**입니다.
`work/v17`은 저장소·문서·권한·검색 공통 코드이므로 삭제하지 않습니다.
화면 소스를 고칠 때만 Node.js/npm을 설치하고 `프로그램/b2-service`에서 실행합니다.

```powershell
npm ci
npm run build
npm test
..\b2-model\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
..\b2-model\.venv\Scripts\python.exe -m pytest work/v3 -q
```

검사는 임시 데이터와 통제된 AI 응답을 사용하는 부분을 포함합니다. 실제 모델의 답변 품질·속도 검증과 구분합니다.

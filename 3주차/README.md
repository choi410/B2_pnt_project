## 최신 v5 실행

접속 주소는 <http://127.0.0.1:8776/>입니다. 처음 실행하면 가상 프로젝트·회의록 예제가 준비됩니다. 설치 및 AI 환경 준비 방법은 [v5 안내](v5/README.md)를 확인하세요.

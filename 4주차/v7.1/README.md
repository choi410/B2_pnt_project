# PNT 회의록 서비스 v7.1

프로젝트별 회의록과 변경이력을 관리하고, AI 답변에서 회의록 원문을 확인할 수 있습니다. 첫 실행은 프로젝트와 회의록이 비어 있는 상태로 시작합니다.

## Windows에서 실행

1. Python 3.12 64비트를 설치합니다. Python Launcher가 설치되어 있으면 설치 파일이 해당 버전을 자동으로 찾습니다.
2. `설치.cmd`를 한 번 실행합니다. 설치 패키지를 받으려면 인터넷에 연결되어 있어야 합니다.
3. `실행.cmd`를 실행하고 브라우저에서 이름을 선택합니다. [v7.1 로컬 접속](http://127.0.0.1:8779/)

화면은 빌드된 상태로 포함되어 있어 실행할 때 Node.js가 필요하지 않습니다. `127.0.0.1` 주소는 실행한 PC에서만 열립니다.

## AI 모델 설치

새 회의록의 AI 분석과 모델이 필요한 챗봇 답변에는 CUDA와 BF16을 지원하는 NVIDIA GPU가 필요합니다. 기본 설치 후 `AI설치.cmd`를 실행하면 AI 라이브러리와 Qwen3-4B 및 multilingual-e5-small 모델을 내려받습니다. 설치가 끝나면 서비스를 다시 실행합니다.

이미 동일한 모델을 보유하고 있다면 `PNT_MODEL_DIR` 환경 변수로 `base`와 `multilingual-e5-small`이 들어 있는 폴더를 지정할 수 있습니다. Python Launcher를 사용하지 않는 PC에서는 `PNT_INSTALL_PYTHON`에 Python 3.12 실행 파일 경로를 지정할 수 있습니다.

## 작업 데이터

새로 만든 자료는 `프로그램/b2-service/data/v7.1`에 저장됩니다. 개인 설정 파일, 작업 DB, 설치된 의존성 및 모델 가중치는 Git 제외 대상입니다.

## 최신 v7.1 실행

Python 3.12 64비트를 설치한 뒤 `v7.1` 폴더에서 `설치.cmd`, `실행.cmd` 순서로 실행합니다. 접속 주소는 <http://127.0.0.1:8779/>입니다. 프로젝트와 회의록은 빈 상태로 시작합니다.

AI 분석과 모델을 사용하는 답변을 준비하려면 `AI설치.cmd`를 실행합니다. 설치 조건과 기존 모델 사용 방법은 [v7.1 안내](v7.1/README.md)를 확인하세요. 실행 후 작업 데이터는 `v7.1/프로그램/b2-service/data/v7.1`에 저장됩니다.

## 이전 작업본 실행

v7은 `설치.cmd`, `실행.cmd` 순서로 실행하며 접속 포트는 `8778`입니다. 가상 예제가 포함된 [v7 안내](v7/README.md)를 참고하세요.

v5.5와 v6는 Python 3.12 64비트를 설치한 뒤 사용할 작업본 폴더에서 `01_처음한번_설치.cmd`, `02_서비스실행.cmd` 순서로 실행합니다.

접속 주소는 <http://127.0.0.1:8777/>입니다. 같은 포트를 사용하므로 한 번에 하나씩 실행합니다. 자세한 실행 방법은 [v5.5 안내](v5.5/README.md)와 [v6 안내](v6/README.md)를 확인하세요.

`v5.5`는 최초 업로드 당시의 코드를 보관한 폴더입니다. 내부 버전 `6.0.0`과 데이터 경로 `프로그램/b2-service/data/v6/`는 원본 설정을 유지합니다. 예제에는 가상 프로젝트 6개, 회의록 11개, 확인된 변경 기록 28개가 포함됩니다.

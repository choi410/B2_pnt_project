# PNT 회의록 서비스 v7

통합 전 v4.2의 회의록 화면과 등록·분석 기능에 최신 챗봇을 적용한 패키지입니다. 가상 프로젝트 6개와 회의록 11건이 기본으로 들어 있습니다.

## Windows에서 실행

1. `v7` 폴더 전체를 받은 뒤 Python 3.12 64비트를 설치합니다. 설치 옵션에서 Python Launcher를 선택합니다.
2. `설치.cmd`를 한 번 실행합니다.
3. `실행.cmd`를 누르고 브라우저에서 이름을 선택합니다. [v7 로컬 접속](http://127.0.0.1:8778/)

기본 설치로 화면, 예제, 등록 자료로 바로 답할 수 있는 챗봇 기능을 이용할 수 있습니다. 브라우저 화면은 빌드되어 있으므로 실행할 때 Node.js가 필요하지 않습니다.

## AI 모델 설치

새 회의록의 AI 분석과 모델을 사용하는 답변에는 CUDA와 BF16을 지원하는 NVIDIA GPU가 필요합니다. `AI설치.cmd`를 실행하면 Python 라이브러리와 Qwen3-4B 및 multilingual-e5-small의 고정 버전을 받습니다. 모델 다운로드에는 인터넷이 필요합니다. 설치 후 서비스를 다시 실행합니다.

같은 모델 파일이 이미 있으면 `PNT_MODEL_DIR`을 `base`와 `multilingual-e5-small`이 들어 있는 폴더로 지정할 수 있습니다. Python 3.12가 등록되지 않은 PC에서는 `PNT_INSTALL_PYTHON`으로 실행 파일을 지정할 수 있습니다.

## 패키지 범위

- 가져온 챗봇 기능에는 프로젝트 요약, 회의록 내용으로 프로젝트 찾기, 용어 설명, 입고 일정 검색, 모델 사용 중 질문 자동 대기가 포함됩니다.
- 회의록은 Word, PDF, Excel `.xlsx`, 텍스트를 등록할 수 있습니다.
- 첫 실행에 가상 예제가 설치됩니다. 사용 중인 데이터는 `프로그램/b2-service/data/v7`에 저장됩니다. 모델 가중치, Python 가상환경, 실제 자료·대화 기록·메일 설정은 Git에 포함하지 않습니다.

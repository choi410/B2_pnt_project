# PNT 회의록 서비스 v8

v7.1의 챗봇 개선에 v7의 회의록 처리 변경을 합친 패키지입니다. 가상 프로젝트 6개와 회의록 11건이 기본으로 들어 있습니다.

## Windows에서 실행

1. Python 3.12 64비트를 설치합니다. 설치 옵션에서 Python Launcher를 선택합니다.
2. `설치.cmd`를 한 번 실행합니다. 설치 패키지를 받으려면 인터넷에 연결되어 있어야 합니다.
3. `실행.cmd`를 실행하고 브라우저에서 이름을 선택합니다. [v8 로컬 접속](http://127.0.0.1:8780/)

화면은 빌드된 상태로 포함되어 있어 실행할 때 Node.js가 필요하지 않습니다. `127.0.0.1` 주소는 실행한 PC에서만 열립니다.

## AI 모델 설치

새 회의록의 AI 분석과 모델이 필요한 챗봇 답변에는 CUDA와 BF16을 지원하는 NVIDIA GPU가 필요합니다. 기본 설치 후 `AI설치.cmd`를 실행하면 AI 라이브러리와 Qwen3-4B 및 multilingual-e5-small 모델을 내려받습니다. 설치가 끝나면 서비스를 다시 실행합니다.

`프로그램/b2-model/llama-cpp/llama-server.exe`와 `프로그램/b2-model/models/gguf/Qwen3-4B-Instruct-2507-Q8_0.gguf`가 있으면 회의록 분석을 llama.cpp 엔진(포트 8786)으로 실행합니다. 없으면 이전처럼 서비스 안에서 모델을 직접 실행합니다. 두 파일은 Git에 포함하지 않으므로 PC마다 복사해 둡니다.

이미 동일한 모델을 보유하고 있다면 `PNT_MODEL_DIR` 환경 변수로 `base`와 `multilingual-e5-small`이 들어 있는 폴더를 지정할 수 있습니다. Python Launcher를 사용하지 않는 PC에서는 `PNT_INSTALL_PYTHON`에 Python 3.12 실행 파일 경로를 지정할 수 있습니다.

## 패키지 범위

- 챗봇(v7.1): 앞 답변의 프로젝트·회의록 선택지로 이어 묻기, "별개로"로 새 주제 시작, 특정 항목 제외, 호기 번호·완료 여부·보류·제안·인수시험·제출기한 질문, 단위(mm, rpm, kPa, %) 근거 확인, 일반 원리 질문, 새 채팅 화면
- 회의록(v7): 회사 회의록 양식 Excel(`.xls`, `.xlsx`) 읽기, 변경값 정리, 프로젝트 이름으로 묻는 요약, llama.cpp 엔진
- 외부 접속이 필요하면 `B2_PUBLIC_HOST`에 터널 주소(예: abc.trycloudflare.com)를 지정합니다.

## 작업 데이터

첫 실행에 가상 예제가 설치됩니다. 사용 중인 데이터는 `프로그램/b2-service/data/v8`에 저장됩니다. 모델 가중치, llama.cpp 실행 파일, Python 가상환경, 실제 자료·대화 기록·메일 설정은 Git에 포함하지 않습니다.

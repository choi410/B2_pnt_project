## 최신 B2 서비스 실행

저장소를 내려받은 뒤 `2주차/v2` 폴더에서 실행합니다. Python 3.12 64비트가 필요합니다. `v2`는 제출 폴더명이며 서비스 버전은 **1.7.2**입니다.

```powershell
git clone --branch v1 https://github.com/choi410/B2_pnt_project.git
cd "B2_pnt_project/2주차/v2"
.\01_처음한번_설치.cmd
.\02_서비스실행.cmd
```

실행 후 <http://127.0.0.1:8771/>에 접속합니다. 설치·공동 테스트·선택 AI 환경 구성은 [2주차 프로젝트 안내](2주차/v2/README.md)를 확인하세요.

1주차 버전은 [기존 프로젝트 안내](1주차/B2-프로젝트/README.md)와 [기존 도커 안내](1주차/B2-프로젝트/DOCKER_README.md)를 참고하세요.

## B2 서비스 실행

저장소를 내려받은 뒤 `1주차/B2-프로젝트` 폴더에서 실행합니다. Python 3.12 64비트가 필요합니다.

```powershell
git clone --branch v1 https://github.com/choi410/B2_pnt_project.git
cd "B2_pnt_project/1주차/B2-프로젝트"
.\01_setup.cmd
.\05_start_manual.cmd
```

자세한 설치·실행 방법은 [프로젝트 안내](1주차/B2-프로젝트/README.md), 도커 사용 방법은 [도커 안내](1주차/B2-프로젝트/DOCKER_README.md)를 확인하세요.

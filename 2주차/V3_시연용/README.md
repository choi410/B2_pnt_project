# PNT 첫 미팅 · B2 시연용

시연용실행.cmd 실행 후 http://127.0.0.1:8772/ 를 엽니다.
김양일(PM), 진효창·배근우·최인혁(담당자) 네 계정으로 빈 상태에서 시작합니다.

- 화면: 홈 → 회의록 등록·원문 대조·AI 정리 → 요구·변경 이력 → 근거 기반 질문.
- 후속 조치는 회의 내용으로 보관합니다. 업무 생성·담당자 배정·완료 검토·협조 요청과 D3 보고서 작성은 이 버전에서 제외했습니다.
- 회의록 등록은 원본 입력 → 정리 확인·수정 → 등록으로 끝납니다.
- 기존 V3와 포트, 로그인 세션, 저장 공간이 다릅니다. 데이터는 b2-service/data/demo/에 저장됩니다.
- 이 PC의 FP/b2-model/.venv와 모델 파일을 재사용합니다. b2-model/models는 기존 모델 폴더를 가리키는 연결입니다. 모델을 중복 다운로드하지 않습니다.
- 이 폴더는 로컬 시연 작업본의 소스 보관본입니다. 실행에는 원래 작업 공간의 Python 환경과 모델이 필요하며, 다른 PC용 설치 패키지는 `../v4`를 사용합니다. 실제 시연 데이터와 설치 환경은 포함하지 않습니다.
- 빈 홈의 회의록·요구사항 숫자는 실제 등록 이후 표시됩니다. 프로젝트 단계는 PM이 입력한 정보이며 AI가 진척률을 추정하지 않습니다.
- Word(.docx) 및 텍스트 입력을 지원합니다. Excel 간트·PDF·이미지 직접 분석은 이번 버전에 포함되지 않습니다.

# PNT 회의록 서비스 · v4

2026-11-13 최신 B2 작업본을 팀원 PC에서 실행할 수 있도록 정리한 Git 소스 패키지입니다.
현재 사용 중인 `V3_시연용`의 화면과 기능을 포함합니다. `v4`는 전달 폴더명이며 최신 화면의 소스 경로는 `work/v3/`입니다.

## 실행 순서 · Windows

1. Git에서 내려받은 `2주차/v4` 폴더를 통째로 사용합니다. ZIP이면 먼저 압축을 풉니다.
2. **Python 3.12 64비트**를 설치합니다. Python Launcher 또는 PATH 등록을 선택합니다.
3. `01_처음한번_설치.cmd` 실행 — 최초 한 번, 인터넷 필요.
4. `02_서비스실행.cmd` 실행 — 실행 창을 열어 둡니다.
5. 브라우저에서 **http://127.0.0.1:8773/** 접속.

화면 빌드 결과를 포함했으므로 기본 실행에 Node.js는 필요하지 않습니다.
종료는 실행 창에서 `Ctrl+C`입니다. 같은 포트가 사용 중이면 해당 실행 창에서 기존 v4를 종료한 후 다시 실행합니다.
이전 V3(8771)·시연 작업본(8772)과 포트·로그인 쿠키·데이터 경로를 분리했습니다.

## 포함 기능

- 프로젝트별 홈, 캘린더·메모, 프로젝트 생성·휴지통.
- 여러 회의록 동시 등록, 프로젝트 연결 제안, 분석 대기·진행 상태 및 조건부 예상 시간 표시.
- 회의록 원본, AI 정리, 근거 대조, 본문 수정·재분석.
- 항목별 요구·변경 이력, 합의·요청·보류·철회 구분, 기록 수정.
- 검색·근거 기반 AI 질문, 통합 휴지통·복원·삭제, 화면 테마·글자 크기 설정.

현재 화면은 B2 중심입니다. 업무 배정·완료 검토와 D3 보고서 작성 화면은 포함하지 않습니다.
`work/v17/`은 최신 서비스가 함께 사용하는 저장소·문서·권한 등의 공통 코드이므로 삭제하면 안 됩니다.
AI 결과는 원문과 대조하고 수정할 수 있습니다. 예상 시간은 유사한 실제 처리 이력이 충분할 때만 표시됩니다.

## AI 사용 준비

**모델 파일과 가상환경은 Git에 포함하지 않습니다.** 새 회의록 AI 분석과 생성형 답변에는 아래 준비가 필요합니다.

1. NVIDIA CUDA GPU·호환 드라이버를 준비합니다. 현재 생성 모델은 BF16 지원 GPU를 사용합니다.
2. `03_선택_AI환경설치.cmd` 실행.
3. `04_선택_모델다운로드.cmd` 실행 — 수 GB 다운로드, 고정 리비전의 공개 모델 사용.
4. `05_환경점검.cmd` 실행 후 서비스를 시작합니다.

| 용도 | 모델 | 위치 |
| --- | --- | --- |
| 회의록 분석·답변 생성 | unsloth/Qwen3-4B-Instruct-2507-bnb-4bit | b2-model/models/base/ |
| 근거 의미 검색 | intfloat/multilingual-e5-small | b2-model/models/multilingual-e5-small/ |

기존에 받은 두 모델 폴더를 위 위치로 복사해도 됩니다. `.venv`는 복사하지 말고 설치 스크립트로 만듭니다.
모델이 없는 PC에서도 화면·프로젝트·파일 등록 등을 확인할 수 있으나 AI 분석은 완료되지 않습니다.
환경 점검 통과는 실제 추론 속도·가용 GPU 메모리·정확도까지 보장하지 않습니다.

## 입력 자료와 원본 미리보기

- Word `.docx`, 글자가 포함된 PDF, Excel `.xlsx`, 텍스트 `.txt`·`.md` 지원.
- Excel은 셀 텍스트를 읽습니다. 색상 막대·도형만으로 표현한 간트 기간은 해석하지 않습니다.
- 스캔 PDF·이미지 OCR은 지원하지 않습니다. 파일당 최대 8MB이며 긴 문서는 나누어 등록합니다.
- Word 원본 페이지 미리보기에는 Microsoft Word 데스크톱 프로그램이 필요합니다.
  Word가 없으면 추출한 텍스트로 확인합니다.

## 저장·Git 업로드

- 소스 업로드 대상은 **이 v4 폴더 전체**입니다. `.gitignore`, `.gitattributes`도 함께 올립니다.
- 로컬 데이터는 `b2-service/data/v4/`에 생성되며 Git에서 제외됩니다.
- `.venv`, `models`, `node_modules`, 업로드·SQLite DB·로그·비밀 설정도 제외됩니다.
- 서버 실행 중 데이터를 덮어쓰지 않습니다. 업데이트 전 필요 데이터는 별도로 백업합니다.
- 기본 실행은 자기 PC의 `127.0.0.1`에만 연결합니다. 비밀번호 없는 테스트 로그인을 인터넷 공개 배포에 그대로 사용하면 안 됩니다.
- AWS·Supabase 공유 데이터베이스 연결은 이 패키지에 포함되지 않습니다.

## 개발

실행 진입점은 **`work.v3.server:app`**입니다. 루트 `server.py`를 직접 실행하지 않습니다.
프런트엔드를 수정할 때만 Node.js/npm이 필요합니다. `b2-service`에서 실행합니다.

```powershell
npm ci
npm run build
npm test
..\b2-model\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
..\b2-model\.venv\Scripts\python.exe -m pytest work/v3 -q
```

기능 테스트는 임시 데이터와 통제된 AI 응답을 사용합니다. 실제 모델의 정확도·속도 검증과는 별개입니다.

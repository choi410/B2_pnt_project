# CHOIN 다른 PC 실행 가이드

내일 다른 Windows 컴퓨터에서 `2주차/V2/CHOIN` 작업본을 바로 실행하기 위한 인수인계 문서입니다.

## 가장 빠른 실행 순서

1. GitHub 저장소의 `v1` 브랜치를 내려받습니다.
2. `B2_pnt_project/2주차/V2/CHOIN` 폴더로 이동합니다.
3. PC에 **Python 3.12 64비트**가 없다면 먼저 설치합니다.
4. 인터넷이 연결된 상태에서 `01_처음한번_설치.cmd`를 한 번 실행합니다.
5. 설치가 끝나면 `02_서비스실행.cmd`를 실행하고 검은 창을 닫지 않습니다.
6. 브라우저에서 <http://127.0.0.1:8771/>에 접속합니다.

기본 서비스와 일정 기능은 AI 모델 없이 실행됩니다. Node.js도 기본 실행에는 필요하지 않습니다.

## 준비물

- Windows 10 또는 11
- Python 3.12 64비트
- 최초 설치 시 인터넷 연결
- 새 DOCX의 PDF 미리보기가 필요하면 Microsoft Word
- 선택 AI 기능까지 사용할 경우 NVIDIA CUDA GPU와 별도 모델 파일

대용량 AI 모델, 가상환경, 실행 데이터베이스는 GitHub에 포함되어 있지 않습니다.

## GitHub에서 받는 방법

### Git 사용

```powershell
git clone --branch v1 https://github.com/choi410/B2_pnt_project.git
cd "B2_pnt_project/2주차/V2/CHOIN"
```

### ZIP 사용

GitHub에서 브랜치를 `v1`로 선택한 후 **Code → Download ZIP**을 누릅니다. 압축을 풀고 `2주차/V2/CHOIN` 폴더로 들어갑니다. ZIP 안에서 직접 실행하지 마세요.

## 5분 시연 순서

1. 로그인 화면에서 `팀원 1`을 선택합니다. 비밀번호는 없습니다.
2. 새 프로젝트를 만들면서 프로젝트 번호, 고객사, 장비·호기, 착수일, 납기일을 입력합니다.
3. 왼쪽 `일정` 메뉴에서 기본 마일스톤과 간트차트를 확인합니다.
4. `엑셀 올리기`를 눌러 `일정_샘플` 폴더의 샘플 파일을 올립니다.
5. `간트차트`, `일정표`, `변경 이력` 탭을 차례대로 확인합니다.
6. 일정 항목의 날짜 또는 진행률을 변경하고 변경 전후 기록이 남는지 확인합니다.

프로젝트가 하나도 없어도 전체 프로젝트 일정 화면에서 Excel 파일을 올리면 `프로젝트` 시트 정보를 기준으로 새 프로젝트를 만들 수 있습니다.

## AI 기능을 사용하는 경우

AI 환경은 선택 사항입니다. `선택_AI환경설치.cmd`를 실행한 다음 아래 모델을 같은 경로에 준비해야 합니다.

```text
b2-model/models/base/
b2-model/models/multilingual-e5-small/
```

- `base`: Qwen3-4B-Instruct-2507 4bit 생성 모델
- `multilingual-e5-small`: 근거 검색용 임베딩 모델
- 생성 모델의 출처와 리비전: `b2-model/model_source.json`

모델이 없더라도 로그인, 회의록 직접 입력, 업무 관리, 일정·간트차트, 변경 이력, Excel 입출력은 사용할 수 있습니다.

## 데이터와 백업

실행 후 생성되는 데이터는 다음 위치에 저장됩니다.

```text
b2-service/data/v17/
```

다른 컴퓨터로 기존 테스트 데이터를 옮기려면 서버를 종료한 뒤 이 폴더 전체를 같은 위치로 복사합니다. GitHub에는 이 폴더가 올라가지 않습니다.

## 자주 생기는 문제

### Python 3.12 오류

Python 3.12 64비트를 설치하고 새 명령창을 연 다음 `01_처음한번_설치.cmd`를 다시 실행합니다.

### 8771 포트를 이미 사용 중이라는 오류

`04_서버_재시작.cmd`를 실행합니다. 이 명령은 8771 포트를 사용하던 기존 서버를 종료하고 CHOIN 서버를 다시 시작합니다.

### 설치 중 pip 다운로드 오류

인터넷과 사내 보안망을 확인합니다. 설치가 완료된 다른 PC의 `b2-model/.venv`를 복사하는 방식보다 대상 PC에서 설치 파일을 다시 실행하는 편이 안전합니다.

### Excel 업로드 오류

`01_처음한번_설치.cmd`를 다시 실행해 `openpyxl`을 설치하고, `.xlsx` 또는 `.xlsm` 파일인지 확인합니다. 가장 확실한 방법은 화면의 `엑셀 양식`을 내려받아 작성하는 것입니다.

### 화면 소스를 수정해야 하는 경우

Node.js를 설치한 뒤 `b2-service` 폴더에서 다음을 실행합니다. 단순 실행만 할 때는 필요하지 않습니다.

```powershell
npm ci
npm run build
```

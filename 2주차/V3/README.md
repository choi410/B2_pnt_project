# PNT 회의록 서비스 - V3 실행 패키지

2026-11-11 현재 작업본입니다. **V3는 전달 폴더명이며 서비스 화면/API 버전은 v2.0**입니다.
v2.0 화면과 최신 보고서 작성 기능을 포함합니다. 이번 패키지에서는 서비스 흐름·디자인을 변경하지 않았습니다.

## 먼저 실행하기 - Windows

1. 저장소의 `v1` 브랜치를 내려받아 `2주차/V3` 폴더를 통째로 사용합니다. GitHub ZIP은 압축을 완전히 풉니다.
2. **Python 3.12 64비트**를 설치합니다. 설치 시 Python Launcher 또는 PATH 등록을 선택합니다.
3. `01_처음한번_설치.cmd`를 더블클릭합니다. 첫 설치에는 인터넷이 필요합니다.
4. `02_서비스실행.cmd`를 더블클릭하고 실행 창을 열어 둡니다.
5. 브라우저에서 **http://127.0.0.1:8771/** 을 엽니다.

Node.js는 기본 실행에 필요하지 않습니다. 화면 빌드 결과가 포함되어 있습니다.
실행이 안 되면 창에 표시된 오류를 확인하거나 `05_환경점검.cmd`를 실행합니다.
이미 8771번 포트가 사용 중이면 기존 서버의 실행 창에서 `Ctrl+C`로 종료한 후 다시 실행합니다.
다른 폴더의 옛 버전을 자동으로 열거나 종료하지 않습니다.

```powershell
git clone --branch v1 https://github.com/choi410/B2_pnt_project.git
cd "B2_pnt_project/2주차/V3"
.\01_처음한번_설치.cmd
.\02_서비스실행.cmd
```

## 계정과 초기 상태

| 로그인 이름 | 내부 계정 | 역할 |
| --- | --- | --- |
| 김양일 | team1 | PM |
| 진효창 | team2 | 담당자 |
| 배근우 | team3 | 담당자 |
| 최인혁 | team4 | 담당자 |

비밀번호 없이 이름을 선택하는 테스트 로그인입니다. 명단 순서에 따라 첫 계정을 PM으로 구성했습니다.
첫 실행에는 위 계정 4개만 생성됩니다. **프로젝트·회의록·업무·알림은 빈 상태**입니다.
PM으로 프로젝트를 만든 후 프로젝트에 참여자를 추가해 사용합니다.

## 온라인 미팅에서 사용할 때

각 PC가 독립 서버입니다. **한 PC에 등록한 회의록이나 업무는 다른 PC에 자동 공유되지 않습니다.**
Git은 소스 코드 공유용이며 데이터 동기화 기능이 아닙니다. 온라인 시연은 한 명의 PC 화면을 공유해 진행하고,
다른 팀원은 자기 PC에서 별도로 테스트할 수 있습니다.
이 실행 스크립트는 자기 PC의 `127.0.0.1`에만 연결합니다. 비밀번호 없는 이 패키지를 인터넷 공개 서버로 사용하지 않습니다.
AWS·Supabase 연결이나 온라인 공동 데이터베이스는 포함되지 않습니다.

## AI 분석이 필요한 PC에서만

기본 설치만으로 화면·회의록 직접 입력/수정·업무·변경 이력 열람 등 일반 기능을 실행할 수 있습니다.
**새 회의록 AI 분석, AI 변경 후보 추출, 의미 검색·생성형 답변, AI 보고서 초안에는 별도 AI 환경과 모델이 필요합니다.**
모델이 없는 상태의 수동 입력 결과를 AI가 분석한 결과로 보여주지 마세요.

1. NVIDIA CUDA GPU와 호환 드라이버가 있는 Windows PC를 준비합니다. 현재 생성 모델은 BF16을 지원하는 GPU를 사용합니다.
2. `03_선택_AI환경설치.cmd`를 실행합니다. CUDA용 PyTorch 등 AI 라이브러리를 설치하며 다운로드 용량이 큽니다.
3. `04_선택_모델다운로드.cmd`를 실행합니다. 공개 모델 두 개를 고정 리비전으로 받습니다. 다운로드는 수 GB이며 시간이 걸립니다.
4. `05_환경점검.cmd`에서 GPU·모델 파일 상태를 확인한 뒤 `02_서비스실행.cmd`로 실행합니다.
5. 회의록 한 건으로 실제 분석 시간과 GPU 메모리 사용을 확인합니다. 환경 점검 성공만으로 추론 속도·가용 메모리가 보장되지는 않습니다.

| 역할 | 모델 | 저장 위치 |
| --- | --- | --- |
| 분석·답변 생성 | Qwen3-4B-Instruct-2507의 unsloth 4bit 배포본 | `b2-model/models/base/` |
| 근거 검색 | intfloat/multilingual-e5-small | `b2-model/models/multilingual-e5-small/` |

모델 파일은 Git에 포함하지 않았습니다. 기존 PC의 위 두 폴더를 같은 위치로 복사해도 됩니다.
가상환경 `.venv`는 다른 PC에서 복사하지 말고 설치 스크립트로 만듭니다.
다운로드 도구는 공개 모델 파일만 받으며 회의록을 전송하지 않습니다. 추론 코드는 로컬 모델을 사용합니다.
GPU가 없는 PC에서는 기본 기능만 시험하고, AI 분석 시연은 준비된 GPU PC에서 화면 공유로 진행하세요.

## 지원 입력과 원본 미리보기

- 회의록 등록: Word `.docx` 또는 텍스트 붙여넣기. Excel 간트·PDF·이미지 직접 분석은 지원하지 않습니다.
- 보고서 작성의 자료 불러오기: Word·Excel·텍스트. Excel은 셀 텍스트를 읽으며 간트 색상 막대/도형을 해석하지 않습니다.
- 새 Word 문서의 원본 페이지 미리보기 변환에는 **Microsoft Word 데스크톱 프로그램**이 필요합니다.
  Word가 없어도 텍스트를 추출해 확인할 수 있지만 원본 페이지 모양의 미리보기는 사용할 수 없습니다.

## 저장 위치와 업데이트

- PC별 데이터: `b2-service/data/v17/` (SQLite, 업로드 파일, 세션 포함).
- Git 제외: 위 데이터, 모델 가중치, `.venv`, `node_modules`, 로그, 비밀 설정, 이전 개발 백업.
- 코드 업데이트 전에는 서버를 종료하고 필요한 경우 `data/v17/`을 별도로 백업하세요.
- 설치 스크립트는 기존 업무 데이터를 초기화하지 않습니다. 계정 이름 초기값은 첫 실행에서만 적용됩니다.

## 개발 및 검증

API 진입점은 **`work.v17.server:app`**입니다. 루트 `server.py`는 공통 문서 처리 코드이므로 서버로 직접 실행하지 않습니다.
주요 소스는 `b2-service/work/v17/`, AI 로딩 코드는 `b2-model/runtime.py`입니다.

화면을 수정해 다시 빌드할 때만 Node.js/npm이 필요합니다. `b2-service`에서 실행합니다.

```powershell
npm ci
npm run build
npm test
..\b2-model\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
..\b2-model\.venv\Scripts\python.exe -m work.v17.test_team
..\b2-model\.venv\Scripts\python.exe -m work.v17.test_registration
..\b2-model\.venv\Scripts\python.exe -m work.v17.test_reports
```

테스트는 임시 데이터 저장소를 사용합니다. 일반 기능 검증과 실제 모델 정확도·속도 검증은 별개입니다.
v1.7.2와 CHOIN 작업본은 저장소의 기존 `V2` 폴더에 그대로 있습니다. 이 패키지에는 해당 작업본을 합치지 않았습니다.

# PNT 프로젝트 업무관리 v2.1_choin

2026년 11월 11일 CHOIN 작업본입니다.

## 설치와 실행

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. Python 3.12 64비트를 설치합니다.
3. `01_처음한번_설치.cmd`를 실행합니다. 처음 설치에는 인터넷이 필요합니다.
4. `02_서비스실행.cmd`를 실행하고 실행 창을 열어 둡니다.
5. 브라우저에서 **http://127.0.0.1:8772/** 로 접속합니다.

기본 실행에는 Node.js가 필요하지 않습니다. 화면 빌드 결과가 포함되어 있습니다.
8772번에서 다른 서버가 실행 중이면 해당 서버를 종료한 뒤 실행합니다.
`05_환경점검.cmd`로 설치 상태를 확인할 수 있습니다.

## AI 정리 실행

1. NVIDIA CUDA GPU가 있는 PC에서 `03_선택_AI환경설치.cmd`를 실행합니다.
2. `04_선택_모델다운로드.cmd`로 생성·검색 모델을 받습니다.
3. `05_환경점검.cmd`에서 CUDA·BF16·모델 파일 상태를 확인합니다.
4. 서버를 다시 실행한 뒤 회의록 등록 화면에서 프로젝트를 선택하고 AI 정리를 실행합니다.

AI 라이브러리와 모델 다운로드는 수 GB입니다.
기존 모델이 있으면 `b2-model/models/base/`와 `b2-model/models/multilingual-e5-small/`에 복사할 수 있습니다.
AI는 로컬 모델을 사용합니다. 첫 분석에는 모델 로딩 시간이 추가됩니다.
가상환경, 모델 가중치, 사용자가 등록한 회의록·첨부·메모·로그인 세션은 이 소스 패키지에서 제외했습니다.
Word 원본 페이지 미리보기 변환에는 Microsoft Word 데스크톱 프로그램이 필요합니다.

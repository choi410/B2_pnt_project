# pnt_1112_demo_choin

2026년 11월 12일 CHOIN 1차 시연 작업본입니다.
11.12_pnt_demo 폴더에서 실제 사용하는 실행 파일을 기준으로 묶었습니다.
업무 공간은 **http://127.0.0.1:8773/**, AI 서버는 **http://127.0.0.1:8080/** 를 사용합니다.

## 설치와 실행

1. 이 폴더를 통째로 내려받아 압축을 풉니다.
2. Python 3.12 64비트를 설치합니다.
3. **01_처음한번_설치.cmd**를 실행합니다.
4. AI 정리 시연에는 llama.cpp의 llama-server가 필요합니다. 명령을 찾지 못하면 07번 실행 창에 표시되는 설치 안내를 따르고 새 창에서 다시 실행합니다.
5. **07_선택_llamacpp_서버.cmd**를 실행하고 AI 서버가 준비될 때까지 기다립니다. 첫 실행에는 약 2.5GB 모델을 다운로드합니다.
6. **02_서비스실행.cmd**를 실행합니다.
7. 브라우저에서 **http://127.0.0.1:8773/** 를 엽니다.

AI 서버와 업무 공간의 실행 창을 열어 둡니다.
8773번 포트가 이미 사용 중이면 해당 서버를 종료한 뒤 실행합니다.
llama.cpp 서버 주소는 B2_LLAMA_URL로 지정할 수 있으며 기본값은 http://127.0.0.1:8080 입니다.
GPU 모델 실행에는 호환되는 llama.cpp 설치와 NVIDIA 드라이버가 필요합니다.
GGUF 분석 경로는 기본 Python 서비스 설치와 llama.cpp 서버를 사용합니다.
03과 04는 별도의 Transformers 기반 모델 환경을 준비하는 선택 도구입니다.

## 시연 화면과 순서

메뉴는 **회의록**과 **변경 이력**으로 구성했습니다.
첫 화면은 회의록 목록입니다.

1. 프로젝트를 선택하고 Word 회의록을 올리거나 본문을 붙여 넣습니다.
2. AI 정리를 실행해 요약·결정사항·후속 사항을 확인합니다.
3. 원문 근거를 대조하고 내용을 수정합니다.
4. 회의록을 등록합니다.
5. 회의 흐름과 요구·변경 이력을 확인합니다.

자세한 동선은 [시연 안내](시연_안내.md)를 참고하세요.

## 포함된 화면과 개발 소스

실제 실행 화면은 b2-service/work/v17/workspace.html이며 같은 위치의 app.bundle.js와 함께 포함했습니다.
실행에 Node.js나 화면 재빌드는 필요하지 않습니다.

이 작업본의 시연 UI에는 빌드 결과를 직접 수정한 내용이 있습니다.
포함된 JSX 소스에서 npm run build를 실행하면 시연 화면과 다른 화면이 생성될 수 있습니다.
원본 폴더의 실행 HTML과 JavaScript를 그대로 보존해 배포했습니다.

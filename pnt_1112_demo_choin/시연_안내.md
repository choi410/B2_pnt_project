# pnt_1112_demo_choin 시연 안내

## 실행 순서

1. 처음 실행하는 PC는 **01_처음한번_설치.cmd**로 기본 환경을 설치합니다.
2. **07_선택_llamacpp_서버.cmd**로 AI 서버를 켜고 준비 완료를 기다립니다.
3. **02_서비스실행.cmd**로 업무 공간을 켭니다.
4. **http://127.0.0.1:8773/** 를 엽니다.

llama-server 설치가 필요한 경우 07번 실행 창의 안내를 따릅니다.
처음 모델 다운로드에는 인터넷과 약 2.5GB 공간이 필요합니다.

## 시연 동선

| 순서 | 화면 | 확인할 내용 |
| --- | --- | --- |
| 1 | 회의록 등록 | 프로젝트 선택과 Word 파일 업로드 또는 텍스트 입력 |
| 2 | AI 정리 확인 | 분석 진행 상태, 요약과 결정사항, 후속 사항 |
| 3 | 원문 대조 | 근거 보기와 내용 수정 |
| 4 | 회의록 등록 | 등록 결과와 흐름 확인 |
| 5 | 회의 흐름 | 같은 프로젝트의 회의별 변화 |
| 6 | 변경 이력 | 요청·보류·확정 등의 변화와 근거 |

이 작업본은 후속 사항을 원문 담당자·기한과 함께 보여주는 시연 구성입니다.
AI 정리 시 AI 서버 창을 계속 열어 둡니다.
업로드 패키지의 초기 프로젝트와 회의록은 비어 있으므로 시연 자료를 준비해 등록합니다.

B2 GitHub v1 검증 기록 - 2026-11-05
애플리케이션 버전: 1.0.0 / 브랜치·태그: v1
저장소: https://github.com/choi410/B2_pnt_project

- 프론트엔드: TypeScript 검사 및 Vite 빌드 통과.
- 모델 없는 별도 설치 환경 및 업로드 파일만 복원한 복사본: 전체 테스트 34개 통과.
- AI 라이브러리가 설치된 개발 환경: 전체 테스트 33개 통과, web-only 조건 검사 1개 건너뜀.
- Starlette TestClient의 httpx 사용에 대한 기존 지원 중단 예정 경고 1건. 테스트 실패는 아님.
- 새 설치에서 테스트가 실행되도록 requirements-dev.txt에 lm-format-enforcer를 명시.
- 데이터 이동 검사는 테스트 전용 DB에서 회의록·업무를 생성하고 SQLite 백업 후 원문·담당자·기한이 유지되는지 확인.
- 저장소에는 사용 중인 DB, 모델 파일, .venv, node_modules, 실행 로그 및 현재 외부 공유 주소를 포함하지 않음.
- 배포 파일의 SHA-256 목록을 GitHub v1에 맞춰 갱신하고 manage.py verify로 확인.
- AI 추출 정확도 전체에 대한 새로운 성능 평가는 수행하지 않음.

알려진 제한
- GA Rev.B 같은 조건형 기한이 날짜 필드로 생성되면 전체 분석이 실패할 수 있음. 원인만 확인했으며 v1에서 수정하지 않음.
- 체험 역할은 실제 로그인이 아님. 임시 링크 공유는 주소를 아는 사람이 조회·수정하는 체험 구성.
- GitHub 새 복사본에는 기존 회의록 DB가 없으며 빈 상태로 시작. 개발용 가상자료는 화면에서 별도로 불러옴.

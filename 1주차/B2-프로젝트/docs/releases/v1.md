## 주요 기능

- 회의록 등록, AI 후보 분석과 직접 검토, 업무 등록 및 PM 검토
- 안건별 업무 흐름과 결정 사항, 담당자·기한·조치 기록
- PNT-SIM-001의 회의별 요구사항 요청값·승인값·변경 근거 조회
- 이전 회의의 정보만 사용하는 AI 비교와 사용자 검토 결과 관리
- 웹 전용·NVIDIA GPU Docker 구성과 임시 외부 공유
- 연결 복구 후 요구사항 조회 재시도와 작성 중인 메모 보존
- PNT 스타일 가상 회의록 및 오류 분석 보고서 양식

## 설치 범위

소스, 빌드된 화면, 도커 설정, 실행 도우미와 개발용 가상자료를 포함합니다. 사용 중인 DB, 모델 파일, 설치 환경과 로그는 포함하지 않습니다. 모델은 출처·리비전 정보에 맞춰 별도로 준비해야 합니다.

## 알려진 문제

`GA Rev.B` 같은 조건형 기한을 AI가 날짜 필드로 반환하면 전체 분석이 실패할 수 있습니다. 이 현상은 원인 확인 단계이며 이번 버전에서 해결했다고 주장하지 않습니다. 날짜는 미정으로 두고 개정 조건은 작업 내용에 보존하는 처리가 후속 개선 대상입니다.

체험 역할은 실제 로그인이 아닙니다. 임시 외부 공유는 링크를 아는 사람이 조회·수정할 수 있는 가상자료 체험용 구성입니다.

## 검증

- 모델 없는 별도 설치 환경과 업로드 대상 파일만 복원한 복사본에서 전체 테스트 34개 통과
- AI 라이브러리가 설치된 개발 환경에서는 33개 통과, web-only 검사 1개 건너뜀
- TypeScript 검사·프론트엔드 빌드 통과
- 배포 파일 SHA-256 검사와 업로드 파일 범위 점검 수행

세부 내용은 `verification-status.txt`에 기록했습니다. 웹 테스트 통과는 AI 추출 정확도 전체에 대한 평가를 의미하지 않습니다.

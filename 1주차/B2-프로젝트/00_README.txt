B2 웹서비스 - Windows 실행용 / AI 모델 제외
작성일: 2026-11-04

이 압축파일에 들어 있는 것
- 웹 화면과 소스코드, 업무 처리 서버, 설치·실행 파일.
- 앞서 만든 전체 배포본과 같은 저장 기록: 프로젝트 1건, 회의록 2건, 관리 항목 8건, 이력 8건.
- 팀 회의록 양식과 가상 회의록 예시.
- AI 연결 코드와 출처 정보. AI 모델 가중치·토크나이저·모델 설정 파일은 포함하지 않았습니다.
- 원래 PC의 서비스·기록·모델 및 기존 전체 ZIP은 그대로 유지했습니다.

실행 방법
1. 새 폴더에 전체 압축을 해제합니다. ZIP 내부에서 바로 실행하지 마세요.
2. Python 3.12 (64비트)가 없다면 설치합니다.
   https://www.python.org/downloads/windows/
   Python 설치 관리자에서는 py install 3.12로 설치할 수 있습니다.
3. 01_setup.cmd를 실행합니다. 최초 설치에는 인터넷이 필요합니다.
4. 02_start.cmd를 실행하고 창을 열어 둡니다.
5. 브라우저에서 http://127.0.0.1:8766/ 을 엽니다.
6. 다음부터는 02_start.cmd만 실행하면 됩니다. Node.js 설치는 필요하지 않습니다.

모델 없이 사용할 수 있는 기능
- 기존 프로젝트·회의록·업무 기록 조회.
- 프로젝트 생성, PM의 업무 직접 등록, 담당자·기한 수정.
- 담당자의 업무 시작·조치 기록·검토 요청, PM의 보완·완료·재개.
- 원문 근거와 변경 이력 확인, CSV 출력.
- 저장한 회의록에서 조치 필요·조치·완료 상태별 건수 확인 및 필터링, AI 초안 대비 사용자 변경·추가 내용 비교.
- 회의록 검토자·검토 시각과 연결된 업무의 현재 담당자·기한·진행 상태 확인.
- 변경된 PNT 핵심 양식 5종의 섹션·필드 구성과 문서 연결 규칙 확인.
- 새 회의록 입력과 직접 검토. 화면의 'AI로 분석하기'를 누르면 직접 검토 안내가 나오며, 원문을 보며 관리 항목을 직접 추가하고 저장할 수 있습니다.
- 모델이 없으면 02_start.cmd가 직접 검토 모드로 실행합니다. 자동으로 모델을 내려받지 않습니다.
- 05_start_manual.cmd를 실행하면 모델이 추가된 상태에서도 직접 검토 모드로 실행합니다.
- AI가 이전에 생성하고 사람이 저장한 결과는 기록으로 남아 있으므로 볼 수 있습니다. 새로운 자동 분석 결과를 생성하는 것은 아닙니다.

나중에 AI 분석도 사용하려면 - 선택 사항
1. 기존 전체 배포본 또는 원래 PC의 b2-model/models/base 폴더 전체를 가져옵니다.
   가중치 한 파일만 복사하지 말고 토크나이저·설정 등을 포함한 base 폴더 전체를 복사하세요.
2. 압축을 푼 폴더 안에서 아래 위치가 되도록 배치합니다.
   B2_WebService/b2-model/models/base/model.safetensors
   같은 base 폴더에 config.json, tokenizer.json, tokenizer_config.json 등의 파일이 함께 있어야 합니다.
3. NVIDIA CUDA·BF16 지원 GPU가 있는 Windows PC에서 03_setup_ai.cmd를 실행합니다.
   이 파일은 AI 라이브러리를 설치합니다. 모델 파일은 내려받지 않습니다. 모델이 없으면 설치 전에 안내하고 중단합니다.
4. 04_check.cmd로 구성요소와 GPU 인식 여부를 확인한 뒤 02_start.cmd를 실행합니다.
5. AI 분석 결과는 누락·오류가 있을 수 있으므로 원문을 대조해 검토합니다.

AI 분석 구조
- 구조 이름: 하이브리드 듀얼 엔진.
- 1단계 문서 해석 엔진: Qwen3-4B-Instruct-2507 4bit가 회의록에서 요구·변경·후속 조치 후보와 근거를 추출합니다.
- 2단계 근거 규칙 검증 엔진: Pydantic 스키마와 원문·날짜·상태 규칙이 형식과 근거를 검증합니다.
- 두 번째 엔진은 별도의 생성형 AI 모델이 아니라 결과를 제한하고 검증하는 결정형 규칙 엔진입니다.

저장 및 주의사항
- 기록은 b2-service/data/meetings.sqlite3에 저장됩니다.
- PC 사이에 기록이 자동 동기화되지 않습니다. ZIP은 이전 포장 시점의 사본입니다.
- 사용 중인 폴더 위에 이 ZIP을 다시 풀면 기록을 덮어쓸 수 있으니 새 폴더에 해제하세요.
- 다른 PC의 .venv 폴더를 복사하지 말고 각 PC에서 01_setup.cmd로 설치합니다.
- 체험 역할 전환은 실제 로그인 기능이 아닙니다. 해당 PC의 로컬 주소에서 사용하는 버전입니다.
- AWS·Supabase, 사진 첨부, 질문하기와 보류한 와이어프레임은 이 배포본에 추가하지 않았습니다.
- 처음 설치할 때 인터넷과 Python이 필요합니다. 완전 오프라인 실행 환경을 통째로 포함한 파일은 아닙니다.

오류가 생기면
- Python 없음: Python 3.12 64비트 설치를 확인하세요.
- 주소 사용 중: 기존에 실행한 B2 창이 있는지 확인하세요.
- 실행 창의 마지막 오류 문구와 04_check.cmd 결과를 전달해 주세요.

개발 및 검증
- 화면 원본: b2-service/src, 빌드된 화면: b2-service/dist.
- 서버: b2-service/server.py, 업무 처리: b2-service/workflow.py.
- 개발 중 화면 변경 시 b2-service에서 npm ci 후 npm run build를 실행합니다.
- API 문서: 실행 후 http://127.0.0.1:8766/docs
- 테스트 구성 설치: .venv\Scripts\python.exe -m pip install -r requirements-dev.txt
- 테스트: b2-service 폴더에서 ..\.venv\Scripts\python.exe -m pytest -q
- 무결성 확인: .venv\Scripts\python.exe manage.py verify
  사용 중 변경되는 데이터베이스와 별도로 추가하는 모델은 무결성 목록에서 제외되어 있습니다.
- AI 모델 파일을 제외한 패키지이며, 모델의 성능이나 다른 실제 PC에서의 실행을 새로 검증한 것은 아닙니다.
